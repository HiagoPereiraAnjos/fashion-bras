SIMULAÇÃO DE CMS NO FRONTEND
----------------------------------------------------------------

Mesmo sem backend, criar a estrutura do frontend pensando em um CMS futuro.

Para isso:
- criar arquivos de dados mockados separados
- criar objetos JSON/TS para banners, lojas, posts, parceiros e configurações
- organizar tudo para que no futuro seja fácil trocar mock por API

Exemplo:
- siteSettings
- homeData
- storesData
- blogPostsData
- partnersData
- leasingData

Também criar componentes reutilizáveis para:
- banners
- cards
- grids
- seções institucionais
- CTA sections
- galerias
- formulários visuais
- listagens dinâmicas
